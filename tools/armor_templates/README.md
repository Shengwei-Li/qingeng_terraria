# 盔甲排布模板

这几张图来自 tModLoader 官方示例模组（ExampleMod，tModLoader 仓库 1.4.4 分支，MIT 许可），
只用来提供 Terraria 盔甲贴图的帧排布和轮廓。`tools/make_armor.py` 会保留轮廓、按青衫的配色重绘。

- ExampleRobe_Body.png：上身（躯干 + 袖子），9×4 帧，每帧 40×56
- ExampleRobe_Legs.png：长袍下摆（画在腿部图层），20 帧竖排，每帧 40×56
- ExampleLeggings_Legs.png：护腿/靴子，20 帧竖排
- ExampleHelmet_Head.png / ExampleHood_Head.png：头部，20 帧竖排，用来确定头的位置
